ANS-100 EXPERIMENT · DIALOGUE R-STDP

Экспериментальная диалоговая спайковая сеть

4 LIF-DT · 256 ПРИЗНАКОВ

Небольшой отдельный эксперимент: 4 выходных LIF-DT нейрона и по 256 признаковых синапсов на каждый. Сначала поступают текстовые признаки, затем отдельный импульс решения; веса меняются только после того, как вы явно выберете правильную метку. Это не языковая модель и не самостоятельное понимание смысла. Отдельный разреженный классификатор с 10 000 признаковых слотов не является этой спайковой сетью.

Загрузка состояния диалоговой R-STDP сети…

Никакого скрытого обучения по переписке: нажатие кнопки создаёт отдельный feedback ID и применяет награду R-STDP. В хранилище записываются числовые состояния, метки и идентификаторы событий; исходная фраза не сохраняется. Эксперимент пока не управляет обычными ответами JARVIS.

JARVIS получит ограниченный фрагмент страницы как недоверенный контекст. Источник будет добавлен к сохранённому ответу.

Расширение Chrome / Edge: нажмите «Скачать расширение», распакуйте ZIP, откройте chrome://extensions или edge://extensions, включите режим разработчика и выберите «Загрузить распакованное». Затем подключите расширение токеном из окна JARVIS Core. Оно открывает сайты/поиск в новых вкладках, а текст текущей страницы передаёт JARVIS только после вашего нажатия.

Первая версия видимого Chromium выполняет только GET/HEAD навигацию. Отправка форм, покупки, сообщения, загрузка файлов и выполнение команд отключены. Для этого отдельного браузера требуется установленный Playwright и Chromium; расширение работает с обычными вкладками Chrome / Edge без отдельного Chromium.

OFFLINE TRANSFER V1

Зашифрованный перенос

AES-256-GCM

Переносите рабочее пространство между Android и Windows через файл. Пароль не сохраняется и не отправляется на сервер. Используйте длинную уникальную парольную фразу.

Импорт не перезаписывает существующие записи: одинаковые ID пропускаются, конфликтующие записи остаются локальными. Перед импортом показывается предварительный результат.

Резервная копия и восстановление

Файл .jwb — это зашифрованная точная копия общей памяти. Восстановление ЗАМЕНЯЕТ её содержимое. Перед этим обязательно сохраните отдельную копию текущей ревизии.

.jwb содержит только общую переносимую память, но не JPVR-файл задач/сессий, черновики Android, токены, ключи или нейронные checkpoint. При повреждении самого JPVR-файла сначала сохраните оригинал и используйте отдельную проверку JPVR recovery.
