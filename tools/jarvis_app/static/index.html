Подключение к JARVIS

API V2

Скопируйте одноразово показанный токен из Termux и вставьте его сюда. Токен действует только на этом устройстве и хранится в памяти вкладки до её закрытия.

Если токен потерян, остановите консоль и запустите её с параметром --rotate-token. Старый токен после ротации перестанет работать.

OFFLINE TRANSFER V1

Зашифрованный перенос

AES-256-GCM

Переносите рабочее пространство между Android и Windows через файл. Пароль не сохраняется и не отправляется на сервер. Используйте длинную уникальную парольную фразу.

Импорт не перезаписывает существующие записи: одинаковые ID пропускаются, конфликтующие записи остаются локальными. Перед импортом показывается предварительный результат.
